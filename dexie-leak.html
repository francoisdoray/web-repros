Dexie Connection Leak

Creating Dexie objects every millisecond without closing them explicitly.

Status: Addressed

This leak was resolved upstream in Dexie.js and is also mitigated browser-side in Chrome:

  • Dexie.js fix: Dexie PR #2250 (and follow-up PR #2254) stopped holding unclosed instances indefinitely in the global connections array.
  • Chrome mitigation: CL 7801367: [indexeddb] Deduplicate connections reuses existing connections when possible to prevent connection flooding even when pages or libraries hold connections open (ongoing experiment).

This repro creates a new Dexie instance every millisecond. These instances go out of JavaScript scope are still reference by Dexie's internal connections array.
