AudioContext Leak

Creating new AudioContext objects without explicitly closing them.

This repro exposes two problems with AudioContext:

  1. CPU Spike: Creating even a single AudioContext uses CPU. (Check Task Manager when creating one.)
  2. OOM Crash: Calling new AudioContext() repeatedly will quickly crash the tab. An AudioContext uses memory even if not explicitly retained by the page, and must be closed explicitly.
