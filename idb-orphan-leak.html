IndexedDB Orphaned Data Leak

Generating massive "ghost" data by race-conditions during database deletion

Step 1: Fill Database

Suggested to make the CompactRange that happens as part of deleteDatabase slower. Filling the database with 10 databases of 200,000 keys each increases quota usage by ~72MiB. You only need to do this once.

Step 2: Leak Test

Trigger the race condition by clicking "Start Leaking". This starts a high-frequency loop that:

  • Opens 10 unique databases in parallel.
  • Fills each with 2MB of data (20 keys of 100KB).
  • Waits exactly 50ms after the transaction completes.
  • Immediately closes and deletes each database.

Every 60s, the script will pause, delete all leak test databases, and wait 10s to check the residual quota.
